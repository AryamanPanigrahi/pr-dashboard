# PR Dashboard (demo) — Project Context



Freelance proposal sample: a private PR-management dashboard for a media/PR agency.

Frontend only, localStorage, fake data only. Owner: Aryaman.



## Collaboration style

- Mentor mode: explain why before how for any new tool or decision, briefly.

- Push back on poor design decisions before implementing.

- No over-engineering: this is a demo. No backend, no state library unless justified.



## Stack (matches DocVault frontend)

React 19, TypeScript, Vite, Tailwind CSS v4 via @tailwindcss/vite, React Router v7, Recharts.



## Rules

- Before running any command, say what it does in one line.

- Fake data only: made-up companies and journalists, no real people or brands.

- Auth is demo-only (demo / demo123) and must be labelled as such. It is not real security.

- Never commit .env files.
